# Origin风格统计图模板（2026-10-12确认）

用于用户的科研统计曲线、散点与误差棒图，尤其快速汇报。用户要求今后这类图默认沿用；机理示意、整页PPT和App演示不套本模板。当前明确要求或指定源模板优先。已明确图形任务时直接按模板绘制，不为了套用模板再问两轮或重新给两个布局。

## 物理页面与版式

- 独立单图默认272×208 mm。用户已从Origin Graph→Print/Dimensions确认单位为Window(mm)。不要把页面单位与图层百分比混淆。
- 图层占页面：左13.98%、上7.531%、宽77.51%、高74.33%。Matplotlib axes=[0.1398,0.18139,0.7751,0.7433]。
- 100%页面下验收字号和描边；允许插入PPT后整体等比例缩放。不自动tight裁剪破坏页面尺寸。不非等比拉伸字体/符号。
- 透明背景、无白色底布；黑色完整矩形轴框、默认无网格、刻度朝内；图例置于图内空白区，避开数据。小图按完整页面整体缩放，不能只缩图层而保留巨大文字。
- 原Origin截图选择了“随图层框架一同缩放”；不能仅凭界面字号推定修改图层后的实际字号。跨软件输出以这里的最终物理pt为准，不冒称Origin像素级复刻。

- 纵轴底端必须为0，顶端必须是明确显示数字的主刻度，不在最高标注上方额外留无标注区间。一般0–100提升图使用刻度0/20/40/60/80/100；基准点留白例外见下条。坐标边界上的符号保持完整、中心不移位。若真实负值或误差范围低于0，不得为版式隐藏数据，须说明与零下界规则的冲突并按当前科学内容处理。

- 用户明确指定的单图例外优先：H018相对a3提升图允许0线下方少量留白，纵轴范围−5到100，标注0/20/40/60/80/100，顶部100顶格；下界−5不另加标签，用于完整显示a3基准点。这是本图例外，不自动套用所有图。

## 字体与点数

|对象|默认设置|
|---|---|
|英文、数字、单位|Times New Roman Bold正体|
|变量|Times New Roman Bold Italic，普通Unicode字符+真实斜体|
|中文|微软雅黑Bold|
|横纵轴标题|36 pt|
|横纵轴刻度|34 pt|
|坐标框线|3 pt|
|数据连线|3 pt（首版采用的可调默认）|
|符号|10 pt|
|误差棒线宽|3 pt|
|误差棒端帽|全宽8 pt|
|图内图例|28 pt，拥挤时20 pt|
|必要图内说明|20 pt，避免增加长脚注|

1pt=1/72inch≈0.3528mm。符号10默认point长度，不能当像素、散点面积s=10或数据坐标单位；圆形的Origin Size based on模式可能影响实际外观，需精确复刻时核对。Matplotlib plot markersize=10；端帽用全宽8pt的横线或验证capsize参数的全宽/半宽映射，不直接把Origin的8盲填为半宽8。

H分组沿既有颜色和符号：0.08青方形、0.13红圆形、0.18绿上三角、0.23橙下三角、0.28紫菱形。此映射仅用于对应层高研究，不强制其他研究也用五色。

## 数据与误差

- 从用户原表读已选记录，核对每组n、均值、SD/SEM列与原导出统计。横坐标采用数据定义，名义宽度与实测平均宽度不可混用。
- SD、SEM、CI必须按当前图的统计含义确定，不为了视觉效果更换。模板只固化外观，不把本次传播标准误强加给所有后续统计图。
- 以相对基准组的提升率为例：G=100(m_a/m_3−1)。用户要求表示平均提升率不确定性时，采用±1传播标准误，并计入基准组误差。独立组均值一阶传播SE_G=100√[(SE_a/m_3)²+(m_a SE_3/m_3²)²]，SE=SD/√n。a3自身归一化固定0，误差0；其他点共享分母有相关性。不能解释为95%CI，也不含未量化系统误差。
- 用户要求仅实测时，只连接实测点，不加模型或平滑；连线用途在配套图注中说明。

## 交付与检查

- 删除无用白底、无色占位边界、空组与冗余clipPath；只有实际承担数据裁剪功能的对象才保留。PNG默认透明，SVG不添加画布背景矩形；参照SKILL.md的干净图稿规则。
- 可编辑文字SVG（物理mm尺寸，viewBox按pt换算）+PNG预览+300dpi PNG；提供绘图数据CSV与简短口径说明。未要求时不改原工作簿/PPT。
- 字体实际字重/字符覆盖核对，数学不把全角等号交给TNR。PNG和SVG至少检查一份实际渲染；字号/线宽/页面/裁切须核验。
- 给用户预览图和可编辑文件入口。科学解释与误差口径放图注或伴随说明，避免塞满画面。

## 跨设备使用

- 在目标设备安装Times New Roman（Bold/Bold Italic）及微软雅黑Bold后再绘图，按字体族名称定位；不依赖某台Windows电脑的绝对字体路径。缺字体时明确提示，不静默换字体后声称完全符合模板。
- 保持整个research-figure-demo目录及references子目录完整。模板不依赖本地实验路径，也不随附实验数据。
